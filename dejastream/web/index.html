What do these four lines mean?
Static
Trains once and never adapts. The baseline.
Retrain on drift
Detects drift, then trains a brand-new model every time. Remembers nothing.
DejaStream v1
The original method. On drift it summarises recent data as a 17-number fingerprint (nine of them use the labels) and reuses the model of a similar past concept if it finds one.
DejaStream MV
Multi-view version. Its fingerprint covers statistics, distribution and time behaviour and needs no labels; a recalled model is tested on labelled data before it is used, and rolled back if it fails.
